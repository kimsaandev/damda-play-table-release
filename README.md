# 담다 · 빛놀이 테이블 (다운로드)

미니 프로젝터 + 스마트폰(또는 웹캠)만 있으면 **우리 집 식탁이 빛 놀이터**가 되는
1~3세 아기를 위한 무료 Windows 프로그램입니다.
테이블 위에 놀이 화면을 비추면 아이가 손으로 톡! 쓱! 만지며 놀아요.

## 다운로드

➡ [**최신 버전 받기 (Releases)**](https://github.com/kimsaandev/damda-play-table-release/releases/latest)

- `LightPlayTable_v1.0_win64.zip` 압축을 풀고 `빛놀이테이블.exe` 실행
- 설치 불필요(Python·Godot 없이 실행), 인터넷 없이 동작
- 처음 실행 때 Windows SmartScreen 경고가 뜨면 **추가 정보 → 실행**을 누르세요.
- 자세한 사용법은 압축 안의 `사용법.txt`

## 준비물

- Windows 10/11 64비트 PC
- 미니 빔 프로젝터 (테이블 위에서 아래로)
- 스마트폰 **(추천, 무선)** — DroidCam·Iriun 같은 '폰을 웹캠으로 쓰는 앱'을 폰과 PC에 설치, 같은 와이파이 / 또는 USB 웹캠

## 안내

- 광고 없음 · 회원가입 없음 · 카메라 영상은 PC 밖으로 나가지 않습니다.
- 그림은 모두 직접 그린 오리지널이며 다른 회사의 캐릭터·노래는 들어 있지 않습니다.
- 사용한 오픈소스와 소리 출처는 압축 안의 `라이선스_및_출처.txt`를 보세요.
- 소스 코드는 비공개 저장소에서 관리됩니다. 이 저장소는 배포(다운로드)용입니다.
